# Space Mission Analysis (1957 - Present)

## Overview
This repository contains an end-to-end Exploratory Data Analysis (EDA) and Predictive Machine Learning pipeline for global space mission launches since 1957.

## Key Deliverables Included
1. `space_mission_analysis.py`: Complete Python data pipeline for dataset cleaning, EDA, visualization generation, and Random Forest prediction.
2. `space_mission_analysis.pptx`: 10-slide PowerPoint presentation formatted with custom dark cosmos branding, metric cards, tables, and risk matrices.
3. `README.md`: Project summary and instructions.

## Key Insights
- **Total Missions Analyzed**: 4,324+ launches across global space agencies and private operators.
- **Historical Reliability**: Mission success rate evolved from ~72% during the early Space Race to >96% in modern commercial operations.
- **Market Dynamics**: Private entities (SpaceX, Arianespace) now command orbital cadence historically led by government defense programs.
